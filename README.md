# FOC-Controller-PCB
This is 6 layer PCB designed for 48V BLDC motor. The PCB houses onboard magnetic sensor for position sensing. Since the PCB is small it can directly be mounted on the back of a motor. Please note that the PCB is yet to be tested and verified.
